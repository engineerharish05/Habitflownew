# HabitFlow

**Build your future with today’s habit.**

A Flutter habit tracker designed for Android.

## Included
- Today + Upcoming
- Habit schedules
- Completion tracking
- Haptic feedback
- Calendar overview
- Per-habit calendar summaries
- Profile with editable name and gallery photo
- Total habits, completions, streaks, best streak and completion rate
- Achievements
- Light / Dark / System themes
- Purple Material 3 design
- CSV statistics export
- JSON backup export
- GitHub Actions APK build

## Build with GitHub Actions
Push this project to a GitHub repository. Open **Actions**, choose **Build HabitFlow APK**, and run it. The generated `app-release.apk` is uploaded as an artifact.

## Important
This release keeps reminders as a UI placeholder. Notification scheduling is not enabled yet, so the app does not claim to send reminders.
